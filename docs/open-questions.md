# Open questions

Each has a working assumption. Build on the assumption; change it when the client answers.

| Question | Working assumption |
|---|---|
| Should Stream run on its own address in the demo too? | No: `/stream` in the same app, so the live sync works without a backend. Labels show stream.npftv.net. A separate demo address would need a small shared data service |
| Team size and deadline for the demo? | 2 developers, about 4 weeks |
| Can we use more real photos and video clips from NPFTV? | Yes, as imagery only, and only without identifiable public figures. Every story and quote stays fictional |
| Who owns the OpenAI account, and what's the monthly spending cap? | Our team's account, with a hard cap set on the OpenAI project |
| Where will the demo be hosted? | Vercel, on a separate demo address, never the live npftv.net |
| Do we have official logo files and brand fonts? | Logo from npftv.net (web resolution). Zilla Slab headings + Archivo body. Ask for vector logo files |
| Which languages should the demo show? | English, with Hausa and Pidgin as AI drafts; Yoruba and Igbo later |
| Is there a real clip for the live player? | Use the parade still with a subtle motion loop until NPFTV supplies a clip |
| Hausa copy | The Hausa headline in the copy desk is an unreviewed draft: have a Hausa speaker check it before anyone sees the demo |

## Questions for the real build (not the demo)

From the PRD draft: broadcast feed source and format (terrestrial, satellite, cable), expected concurrent viewers, streaming provider and budget, hosting/domain ownership, editorial approval hierarchy, state command contribution process, content migration volume, data retention and privacy rules, support and incident escalation.
